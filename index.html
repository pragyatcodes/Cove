How sharing works

Public links share one item only — never your whole inbox. Each link is an unguessable token (not the internal ID). You can revoke it anytime; deleted items show “unavailable”.
⬡

Private by design

Each item stores ownerId. Firestore Rules / RLS check auth.uid == ownerId for every read/write. Client filter alone isn’t enough. See README for the exact rules.

Privacy test — try it

We enforce owner checks on the backend, not just the UI. Tap to simulate Account B trying to steal Account A’s item by guessing its ID.
